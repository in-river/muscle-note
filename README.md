# MuscleNote 💪

**筋力トレーニングの記録・保存・可視化を行うPython製デスクトップアプリケーションです。**

トレーニング種目、重量、回数、セット数を記録し、

**重量 × 回数 × セット数**

から総負荷量を計算します。

保存したデータは履歴一覧やグラフから確認でき、過去のトレーニングとの変化を振り返ることができます。

## 🎯 制作背景

筋力トレーニングを継続する中で、単純に「何kgを持ち上げたか」だけでなく、

**トレーニング全体でどれくらいの負荷をかけたのかを記録し、過去と比較したい**

と考えたことから制作しました。

また、Pythonの学習として個別の処理を書くことだけではなく、

**入力 → 計算 → 保存 → データ処理 → 可視化**

までを一つのアプリケーションとして実装することを目的としました。

---

## ✨ 主な機能

### 📝 トレーニング記録

以下の情報を入力してトレーニングを記録できます。

* 日付
* トレーニング分類
* 種目
* 重量
* 回数
* セット数

日付はアプリ起動時に当日の日付が自動入力されます。

---

### 🏋️ 分類・種目選択

トレーニングを

* プッシュ
* プル
* スクワット

などの分類から選択できます。

選択した分類に応じて種目候補を表示し、プルダウンから種目を選択できます。

また、必要に応じて新しい種目を追加できます。

---

### 📊 総負荷量の計算

入力されたデータから、トレーニングの総負荷量を計算します。

```text
総負荷量 = 重量 × 回数 × セット数
```

例：

```text
ベンチプレス
60kg × 8回 × 4セット

総負荷量 = 1,920kg
```

重量だけでは分かりにくいトレーニング全体のボリュームを数値として記録できます。

---

### 💾 CSVへのデータ保存

記録したトレーニングデータはCSVファイルへ保存します。

保存項目：

* 日付
* 種目
* 重量
* 回数
* セット数
* 総負荷量

アプリを終了しても過去のデータを保持できます。

---

### 📋 記録履歴の表示

保存したトレーニングデータをアプリ上で一覧表示できます。

過去の

* 重量
* 回数
* セット数
* 総負荷量

を確認できるため、以前のトレーニング内容を簡単に振り返ることができます。

---

### 📈 総負荷量の可視化

Pandasを利用してCSVデータを読み込み、Matplotlibを利用して総負荷量の推移をグラフ化します。

同じ種目の記録を時系列で表示することで、トレーニング量の変化を視覚的に確認できます。

---

### 💬 記録結果のフィードバック

保存した記録をもとに、過去のトレーニングとの変化を確認できる簡易フィードバックを表示します。

## 💡 工夫した点

### 1. トレーニング量を数値化

単純な重量だけではなく、

```text
重量 × 回数 × セット数
```

による総負荷量を使用しました。

これにより、重量や回数が異なるトレーニングでも、トレーニング全体のボリュームを比較できます。

### 2. 記録から可視化までを一つのアプリに統合

データを保存するだけでなく、

**記録 → CSV保存 → データ加工 → 履歴確認 → グラフ可視化**

までを一つのアプリケーション内で行えるようにしました。

### 3. 種目入力を選択式に変更

種目名を毎回手入力するのではなく、分類と種目をプルダウンから選択できるようにしました。

入力の手間を減らし、表記ゆれによって同じ種目が別データとして扱われることを防ぎます。

### 4. 入力値のチェック

日付形式や重量・回数・セット数などの入力値を確認し、不正な値が入力された場合にはエラーを表示するようにしています。

## 🚀 実行方法

### 1. RepositoryをClone

```bash
git clone https://github.com/in-river/muscle-note.git
cd muscle-note
```

### 2. 仮想環境を作成

Windows：

```bash
python -m venv .venv
.venv\Scripts\activate
```

macOS / Linux：

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. 必要なライブラリをインストール

```bash
python -m pip install pandas matplotlib
```

### 4. アプリを起動

```bash
python workout_app.py
```
